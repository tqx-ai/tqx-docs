A <strong>Skill</strong> is a task guide Qube can read while helping you. It explains how to do a particular job, such as looking up market data or saving a research note. Think of it as instructions for the assistant, rather than a course you must study first.

## What a Skill adds

Suppose you ask Qube to save the reasons behind a strategy. The knowledge Skill explains where and how that note should be stored. A data Skill instead explains how to query data, while factor and strategy Skills explain the rules for those research tasks.

You still describe the goal in conversation. For example:

```text
Save a research note explaining this strategy's buying and selling rules,
the dates we tested, and what the backtest did not establish.
Use the knowledge Skill and show me where the note was saved.
```

A Skill supplies task-specific instructions. It does not make a strategy profitable or replace checking the saved result.

## Recognize the files in the workspace

The workspace lets you inspect Skill files. In the screenshot, the official `qube-wiki` Skill has an instruction file (`SKILL.md`), supporting references, and a helper script. The **read-only** badges mean you can inspect these official files but cannot edit them there.

## When you need more detail

Data used during a conversation and data used inside a submitted strategy have different rules. If you are asking Qube to write code, have it use the guide for that specific task. If you want to inspect the technical details yourself, start with [data environments](/data/qube-runtime) or [strategy code](/qube/research/strategy/code).
