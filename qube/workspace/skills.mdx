Skills are reusable instructions that tell Qube how to query data, author factors, write strategies, save knowledge, or manage schedules. Select the Skill that matches the task before asking the agent to generate or run code.

The Qube data Skill exposes the native historical data runtime. It does not require a local API key. Factor and strategy Skills describe different source contracts; a factor's injected fields are not the same as a strategy's backtest engine APIs.

A Skill improves the instructions available to the agent. It does not bypass validation, revision checks, research execution states, or human review.
