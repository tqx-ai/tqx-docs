Personal knowledge stores durable notes and decisions that you want to reuse across Qube conversations. Save definitions, research conventions, symbol mappings, or review checklists when they are stable and safe to reuse.

Knowledge is context for future work. It is not a source revision, a named version, or evidence that a run succeeded. Link the original file or run when a note depends on a specific result.
