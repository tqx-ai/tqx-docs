TQX CLI lets an AI coding agent connect research and trading in one workflow. The agent uses `tqx research` for Qube factors and strategies, and `tqx trading` to query connected accounts and execute trading decisions within its permissions and risk limits.

## Let your agent install for you

TQX Skills help your coding agent use TQX CLI. Use the copy button in the top-right corner of the text block below, then paste the full prompt into your agent:

```text wrap
Read the installation guide:
https://github.com/tqx-ai/tqx-ts/blob/main/INSTALL.md

Follow the guide to install or update the Skills for TQX CLI. Identify the agent you are running in and use its global Skills directory. Check the existing TQX CLI installation and install or update it as required by the guide.

Verify that all TQX Skills listed in the guide are installed and available to this agent. Report the installation paths and verification results.
```

The prompt above lets your agent install TQX CLI and Skills for you.

## Manually install the CLI

<Tabs>
  <Tab title="Standalone binary">
    Download the current platform asset from the [TQX releases](https://github.com/tqx-ai/tqx-ts/releases), place `tqx` on your `PATH`, and verify it:

    ```bash
    tqx --version
    ```

  </Tab>
  <Tab title="npm">
    Node.js 22.18 or newer is required.

    ```bash
    npm install --global @tqx-ai/cli
    tqx --version
    ```

  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
  <Tab title="bun">
    ```bash
    bun add --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
</Tabs>

## Authenticate

Create an API key in the [TQX account center](https://www.tqx.ai/user-center?tab=ai-accounts), then store it in the CLI credential store:

```bash
tqx login --api-key=<YOUR_API_KEY>
tqx status --json
```

For a single command, set `TQX_API_KEY` in the command environment instead of storing the key. Never put the key in source files or public logs.
