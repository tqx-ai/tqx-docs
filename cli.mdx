The TQX CLI gives an AI coding agent or shell workflow access to TQX research and trading capabilities. Use `tqx research` for Qube factors and strategies, and `tqx trading` for connected accounts and authorized orders.

## Install the CLI

<Tabs>
  <Tab title="Standalone binary">
    Download the current platform asset from the [TQX releases](https://github.com/tqx-ai/tqx-ts/releases), place `tqx` on your `PATH`, and verify it:

    ```bash
    tqx --version
    ```
  </Tab>
  <Tab title="npm">
    Node.js 22.18 or newer is required.

    ```bash
    npm install --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
  <Tab title="bun">
    ```bash
    bun add --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
</Tabs>

## Authenticate

Create an API key in the [TQX account center](https://www.tqx.ai/user-center?tab=ai-accounts), then store it in the CLI credential store:

```bash
tqx login --api-key=<YOUR_API_KEY>
tqx status --json
```

For a single command, set `TQX_API_KEY` in the command environment instead of storing the key. Never put the key in source files or public logs.

## Give an agent the right context

TQX Skills are instructions that help your coding agent use TQX tools. Follow the [Skills installation guide](https://github.com/tqx-ai/tqx-ts/blob/main/INSTALL.md#step-5-install-the-tqx-skills) to install them. The [Qube CLI quickstart](/qube/cli/quickstart) covers research. The [Trading guide](/trading/info) covers account workflows.

<Info>
  The CLI and web workspace use the same Qube research objects. The CLI does not make a backtest successful merely because the request was accepted. Read the run status and result before interpreting it.
</Info>
