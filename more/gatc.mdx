在这里将会帮大家解答gatc是什么？经常问到的问题大致分为四类：怎么进入，比赛本身（包含一些glossary+数据指标），比赛规则细节，奖金问题等

# general：这是什么比赛

1. GATC 是什么？面向哪些人？<br />GATC 是 Global AI Trading Championship，全球首个真实资金、只允许 AI 交易的比赛。由 GATL 联合 TQX、国际券商、算力提供方和 AI 技术平台发起。**全球用户都可以报名。**参赛者须年满 18 周岁，并具备自己所在地的合法证券交易资格。<br />成绩来自已关联的**真实券商账户**。模拟盘成绩不计入比赛。第一阶段的标的是港股和美股。
2. 会消耗 Qube 算力吗？<br />在 Qube 里建策略、做回测，无论用网页还是 CLI，都消耗 Qube 算力。比赛计分不要求 Qube 会员。经 TQX CLI 向已关联的券商账户发送交易指令，不因此扣除 Qube 算力。

# 怎么参赛

1. **怎么进入比赛呢？**<br />按这个顺序做完，才算进入比赛。
   1. 在 TQX 注册竞赛账户。
   2. 关联一个已实名的真实券商账户。
   3. 在 My Agents 里提交参赛，选择本地模型，把 API key 交给编程代理。可用 Codex、Claude Code、Cursor、Trae、GitHub Copilot、Windsurf。
   4. 代理安装并登录 TQX CLI，用workshop上的提示词运行一套可核验的原创 AI 策略。交易指令经 CLI 发到已关联的券商账户。

审核通过后，账户进入当月排行榜和积分。没有单独的策略文件上传页。报名从 2026-07-01 00:00（香港时间）起开放，赛季内可以随时加入。比赛从 2026-08-01 00:00 到 2027-07-31 23:59。

2. **现在能关联哪些券商？在哪里操作？**<br />目前已接通的是：香港 Zhangle、Panda、Tiger；新加坡 Tiger。美国券商尚未接通，其他券商还在陆续接通。<br />打开[账户页](https://www.tqx.trade/en/user-center?tab=accounts)进行关联。

3. Qube 里的策略可以直接用吗？要先买会员吗？<br />Qube 里的策略可以当作底稿，修改后由本地代理经 TQX CLI 执行。平台公开模板原样拿去运行，不视为原创策略。Qube 会员不是上榜条件。
4. 策略跑起来之后，谁来每天检查、每周再平衡？

   比赛系统不会按日或按周替你执行。定时任务设在你自己的编程代理里。每日任务检查持仓并做日频调仓。每周再平衡另设一个每周任务。同时请授予ai agent full access或者及时审核他们发布的请求。
   - Cursor：在 Agent Window 里用 Automations。
   - Codex：用 Scheduled。
   - Claude Code：用 Routines。可在 CLI 里运行 /schedule，或在 [claude.ai/code/routines](http://claude.ai/code/routines) 创建。云端 Routine 在计算机关闭后仍会执行。Desktop 里的本地定时任务只在应用开着、计算机醒着时执行。

# 进入比赛后看什么

1. 排名和成交在哪里看？<br />当月榜： [Championship](https://www.tqx.ai/en/competition?currentPage=2&pageDetail=Championship)。季度和年度榜：[Ranking](https://www.tqx.ai/en/competition?currentPage=2&pageDetail=Ranking)。成交记录：[这里](https://www.tqx.ai/en/competition?currentPage=3)。轻量组和重量组始终分开。
2. 名字没有出现，或者分数不更新。<br />首次参赛后大约 15 分钟会出现在当月榜上。状态如果仍是 Pending，等到第二天不会自动变成已连接。先用 CLI 查询一次账户资金或持仓，状态才会变成 Competing。相关操作超过两小时仍无变化，在 Discord 留言，或写邮件给[ audrey@tqx.ai](mailto:audrey@tqx.ai)。<br />计入成绩的是已关联券商账户中、经 TQX CLI 上报的成交。只在券商 App 里下的单也不计分。
3. 决策可以用哪些数据？<br />可以用来源能够核验的数据，包括券商的实时行情。Qube 里的研究数据覆盖港股和美股：港股代码用 `.HK`，美股用 `.NB`。委托仍须经 TQX CLI 发出。榜上的实时数据最多可能延迟 15 分钟。更多数据内容请[访问这里](https://app.mintlify.com/tqx/tqx/~/TQX-data-e43030cf-189f-4626-8da7-01a8f771331f)。

# 分数怎么来

先分清三个词，后面的规则都用它们。

- 账户权益决定组别。它是账户里的现金加持仓市值，再做比赛规定的调整，以港币计。
- NAV 衡量当月业绩。它不是港币余额。每月重置为 1.0000 时，账户里的钱不会被取出。
- 综合分在 0 到 100 之间，只排列当月实时收益榜。月度积分才是发奖用的数字。

1. 综合分由什么组成？
   | **指标** | **权重** | **怎么理解** |
   | :-- | :-- | :-- |
   | 净收益 | 40% | 当月 NAV 的变动 |
   | 盈利因子 | 10% | 已完成交易的毛利除以毛亏的绝对值。只有在盈利时为 100。没有已完成交易，或只有亏损时为 0 |
   | 胜率 | 5% | 已实现盈利为正的已完成交易占比。没有已完成交易时为 0 |
   | 夏普比率 | 20% | 用当月每日 NAV 收益计算，至少要有 10 个交易日。样本太少，或 NAV 基本没变时，这项为 0 |
   | 最大回撤 | 15% | 评价期内 NAV 从高点的最大跌幅。回撤越小，分数越高。整月没有成交、也没有持仓时为 0 |
   | 风险调整后收益 | 10% | 当月净收益，除以「最大回撤」和「适用的最小回撤阈值」里的较大者，再归一化到 0–100 |

已完成交易只算平仓卖出：代理在平台上先买入、之后卖出才算。按先买先卖匹配，计入卖出的那个月。盈亏是卖出价减去实际买入价，再扣费用。

2. 这个月进哪一组？<br />组别在每个月第一个交易日开市前，按账户权益锁定。<br />- 轻量组：1,000 港币 ≤ 总权益 \< 100,000 港币<br />- 重量组：总权益 ≥ 100,000 港币<br />**月中入金、出金和市值波动都不改变当月组别。**该月第一个交易日之后才审核通过的，按审核通过时的总权益分组，包含当时的持仓。部分香港券商开户要求入金 10,000 港币，那是券商的开户要求。比赛的轻量组从 1,000 港币起算。<br />下个月的组别看下个月月初的权益。如果账户已连续三个月是重量组，之后因为出金在月初低于 100,000 港币，该月仍按重量组计算，除非出金说明通过审核。这里保留你现有的示意图。<br />一个季度或全年的组别，看该周期有效参赛月里哪一组出现得更多。次数相同，归入重量组。
3. 怎样才算这个月的有效参赛？<br />四项都要满足：**有有效参赛资金，当月综合分大于 0，账户处于有效参赛状态，并且 Active Day 达标。**少一项，该月得 0 分，也不计入有效参赛人数。季度奖至少要有 2 个有效参赛月，年度奖至少要有 8 个。

   Active Day 是策略正在运行，并且当天通过 TQX CLI 提交了一次决策的交易日。明确记录「持有、不新开仓」也算。当天没有策略在跑、也没有 CLI 决策，不算。

   可计算的交易日从审核通过当天起，只算股票市场实际开市的日子。要求其中至少 50% 为 Active Day，不是整数时向上取整。审核后还剩 20 个交易日，至少 10 天。还剩 15 天时，7.5 向上取整为 8 天。月底加入的人只从审核通过那天起算。达标后，这个月的积分可以计入季度和年度。
4. 积分怎么从综合分里分出来？<br />每组每月基础池是 100,000 分。实际积分池 = 100,000 × (1 + 0.25 × ln(该组有效参赛人数))。分配权重 = 综合分 ^ 2.6。个人积分 = 实际积分池 × 本人权重 / 本组全体权重之和。单账户每月最多 30,000 分，超出部分不发放，也不分给其他人。两组的积分池不混用。季度和年度积分对应月份相加，不再重复分。
5. 积分相同，名次怎么排？<br />月度奖先比当月积分。相同则比该月最终综合分，再比净收益，再比更低的最大回撤。仍相同，奖金平分。

   季度奖和年度奖先比当期合计积分，再比有效月的平均综合分，然后是净收益、更低的最大回撤。仍相同，奖金平分。

   实时收益榜只按综合分展示。发奖以结算快照为准。截止后的价格变动不改变已经确定的名次。

# 奖金

排名确定之后，按名次发奖。月度奖用当月积分，季度奖用该季三个月之和，年度奖用 12 个月之和。两组分开。

月度成绩在该月结束后结算。正式积分在次月第一个工作日确定，并公示 3 个自然日。8 月成绩在 9 月第一个工作日结算。季度按赛季划分：Q1 至 2026-10-31，Q2 至 2027-01-31，Q3 至 2027-04-30，Q4 至 2027-07-31。

每期奖池（现金 + 算力，港币）：每月重量组 70,000 + 17,500、轻量组 30,000 + 7,500；每季重量组 140,000 + 35,000、轻量组 60,000 + 15,000；全年重量组 1,400,000 + 350,000、轻量组 600,000 + 150,000。区间奖的金额是该区间里每一位获奖者的金额。人数不够时，空缺名次不向上递补，也不转到另一组。

规则没有规定到账天数。按目前的安排，工作人员用电子邮件联系获奖者并收集收款信息。请核对发件人邮箱。奖金在当期结束后 5 个工作日内发放，遇公共假期顺延。转账手续费由收付双方各自承担。纳税由获奖者自行处理。<br />
