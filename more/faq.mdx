## Account setup {#account-setup}

### What if I chose the wrong broker on LongPort? {#wrong-broker-on-longport}

> Scenario: I already selected a different broker on LongPort instead of Panda, and TQX now shows "Unsupported broker".

Go back to [https://open.longportapp.com/dashboard](https://open.longportapp.com/dashboard), click your avatar in the top-right corner, and select **Logout** to sign out, as shown below.

<Frame caption="Click your avatar in the top-right corner, then select Logout">
  <img src="/images/faq/longport-logout.png" alt="LongPort dashboard avatar menu with the Logout option highlighted" />
</Frame>

Then return to [https://www.tqx.ai/en/user-center/longport?broker=panda](https://www.tqx.ai/en/user-center/longport?broker=panda) and start the binding process again.
