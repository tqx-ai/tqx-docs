TQX 是什么？提供什么样的产品？

1. tqx是干什么的呢？提供什么样的产品呢？<br />TQX 是 PandaAI 的国际平台，也是面向 AI 交易的量化操作系统。在同一个平台上，你可以从一个想法走到因子、回测、模拟账户和实盘执行。<br />这条路径上有两个产品：
   - Qube 把一句话变成可运行的策略。这是现在就能用的产品。
   - TQX OS 用来运行整套交易操作。尚未发布。

   从这里开始：[https://www.tqx.ai/en/](https://www.tqx.ai/en/)
2. TQX 适合什么样的人？<br />适合已经在用编程代理并且有一定交易经验的人。<br />- 做研究。 用 Qube。量化研究员可以用一句英文写出因子和策略，并完成回测，少写重复代码。<br />- 打磨策略。 用 TQX CLI 连接模拟账户，在本机把策略跑在模拟盘上。<br />- 参加实盘比赛。 策略稳定之后，可以报名 GATC。参赛者须年满 18 周岁，具备合法证券交易资格，参赛要关联 TQX 目前支持的真实券商账户，由本地编程代理经 TQX CLI 运行原创 AI 策略。<br />
3. 我该如何快速开始呢？<br />- 在 Qube 里用一句英文生成策略，并执行回测。

   - 安装 TQX CLI，连接模拟账户，在本机把同一套策略放到模拟盘上测试。

   - 你对策略有把握之后，再报名 Global AI Trading Championship。比赛使用真实券商账户。模拟盘的成绩不计入比赛。
   ![2c7c7a4e 4bb3 4c00 82c4 07e8725ce438](/images/2c7c7a4e-4bb3-4c00-82c4-07e8725ce438.jpeg "2c7c7a4e 4bb3 4c00 82c4 07e8725ce438")
4. 研究、模拟和参赛要准备几套账户？

   一个 TQX 账户可以进入 Qube。模拟盘和实盘是交易账户的两种模式。参加 GATC 时，再关联一个真实券商账户。<br />

### What if I chose the wrong broker on LongPort? {#wrong-broker-on-longport}

> Scenario: I already selected a different broker on LongPort instead of Panda, and TQX now shows "Unsupported broker".

Go back to [https://open.longportapp.com/dashboard](https://open.longportapp.com/dashboard), click your avatar in the top-right corner, and select **Logout** to sign out, as shown below.

<Frame caption="Click your avatar in the top-right corner, then select Logout">
  <img
    src="/images/faq/longport-logout.png"
    alt="LongPort dashboard avatar menu with the Logout option highlighted"
  />
</Frame>

Then return to [https://www.tqx.ai/en/user-center/longport?broker=panda](https://www.tqx.ai/en/user-center/longport?broker=panda) and start the binding process again.
