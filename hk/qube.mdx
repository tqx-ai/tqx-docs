## Qube 投研循環

設定研究目標後，可以讓 Qube 自行完成投研步驟。編程代理可透過 [TQX CLI](/hk/cli)，在帳戶權限與風險限制內繼續銜接交易。

1. 從市場問題或假設開始。
2. 查詢或準備所需數據。
3. 建立因子或策略。
4. 編寫並驗證程式碼。
5. 執行因子分析或策略回測。
6. 檢查指標、交易、日誌和診斷。
7. 保存命名版本，或調優有限的參數範圍。
8. 在另一段期間重新驗證候選方案。
9. 交易前，讓 Agent 按已設定的交易規則、風險限制及執行條件評估候選方案，再透過 TQX CLI 執行。

<Warning>
  已保存的因子或策略是研究資產。保存程式碼不會自動執行，而歷史結果也不保證未來表現。
</Warning>

## 使用 Qube 的三種介面

<Tabs>
  <Tab title="網頁工作區">
    前往 [Qube
    網頁工作區](https://www.tqx.ai/qube)，透過對話、因子庫、策略庫、執行歷史和工作區建立及檢查研究資產。
  </Tab>
  <Tab title="Qube CLI">
    使用 `tqx research` 管理因子和策略、輪詢狀態、查看結果、版本和調優。
  </Tab>
  <Tab title="TypeScript SDK">
    使用 `@tqx-ai/sdk` 和 `client.research` 編寫自己的 TypeScript
    程式，建立研究、執行回測及讀取結果。
  </Tab>
</Tabs>
