## Qube 是甚麼？ {#what-is-qube}

Qube 是 TQX 面向量化研究的 AI 工作區，串連問題、數據、程式碼、執行、結果及命名版本。先閱讀 [總覽](/hk/qube) 或 [快速開始](/hk/qube/research/info)。

## 如何使用？ {#access}

你可以使用網頁對話及研究資產庫、[Qube CLI](/hk/qube/cli/quickstart)，或 [TypeScript SDK](/hk/qube/sdk/overview)，操作同一套研究資產。

## 儲存會執行程式嗎？ {#history}

不會。儲存原始碼、儲存設定、執行任務及建立命名版本是分開操作。命名版本來自成功的一般執行。參閱 [研究物件](/hk/qube/concepts/research-objects) 及 [執行歷史](/hk/qube/research/run-history)。

## 產生的策略可以實盤交易嗎？ {#live-trading}

Qube 回測屬於研究。請審閱訊號時間、流動性、成本、風險及其他期間的證據。交易帳戶查詢與經授權的訂單屬於獨立的 [交易流程](/hk/trading/info)。歷史結果不能保證未來表現。

## 應使用哪個數據 API？ {#data}

先選擇 [Qube 執行環境](/hk/data/qube-runtime) 或 [本機 API Key 套件](/hk/data/local-package)。Qube 原生 Skill 提供歷史數據，不提供即時 Tick 報價。策略引擎與數據套件的代碼格式可能不同。

## 檔案與知識在哪裡？ {#research-and-execution}

參閱 [工作區檔案](/hk/qube/workspace)、[對話](/hk/qube/concepts/conversations) 及 [個人知識](/hk/qube/workspace/knowledge)。檔案與對話文字不會自動成為正式因子或策略。

## 如何查看方案與用量？ {#subscriptions-and-usage}

請使用 [訂閱頁](https://www.tqx.ai/payment) 及已登入 Qube 帳戶內的用量資訊。價格、資格及額度以該處顯示為準。模型及運算用量因任務而異；失敗或取消的任務仍可能消耗資源。

### 方案 {#plans}

訂閱前請在訂閱頁確認目前條款。

### 帳單 {#billing}

在帳戶查看帳單紀錄及剩餘用量。產生策略與執行回測沒有固定的合併費用。
