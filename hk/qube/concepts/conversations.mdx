Qube 對話是你提出問題、檢查檔案，並要求 Agent 建立或修改研究資產的工作脈絡。對話歷史與正式的因子及策略記錄分開，但你明確提出要求時，回覆可以操作這些記錄。

## 有意識地管理脈絡

- 使用 `@` 引用目前工作區的檔案、資料夾、因子或策略。
- 使用 Skills 提供適用的數據或撰寫規約。
- 送出訊息時，Qube 會擷取所選資產脈絡；未儲存的檔案草稿須先儲存才會納入。
- 需要獨立研究方向時，複製對話建立分支。
- 請求有誤時，停止或編輯佇列中的訊息。

對話輸出在你審閱並儲存適當的原始碼、設定、版本或報告前，都只是提案或工作結果。
