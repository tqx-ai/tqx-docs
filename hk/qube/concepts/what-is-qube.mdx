Qube 是一個 AI 量化研究工作區。它協助你將市場問題轉化為程式碼，使用受控數據執行，並把證據保留在研究資產旁邊。

## Qube 連接哪些內容

- **對話**：描述假設並逐步修改研究工作。
- **工作區**：管理檔案、資料夾、上傳內容、知識和任務產物。
- **數據 Skill**：說明 Qube 執行環境可用的欄位和方法。
- **因子和策略**：保存程式碼及設定的正式研究資產。
- **執行記錄**：凍結一次分析或回測所使用的輸入。
- **結果**：查看指標、圖表、交易、日誌和診斷。
- **版本**：保存可比較、綁定或還原的命名快照。

## 設定 Agent 的目標與授權

你可以設定研究目標、帳戶權限和風險限制，讓 AI Agent 建立及評估研究程式碼、分析結果，並在授權範圍內執行後續操作。

## Qube 與交易

AI Agent 可以透過 [TQX CLI](/hk/cli) 自行串連投研與交易流程。Agent 使用 `tqx research` 建立策略、執行回測並讀取結果，再使用 `tqx trading` 查詢帳戶和持倉、提交訂單及追蹤執行狀態。你可以授權 Agent 在指定帳戶和風險限制內執行仿真或實盤交易，詳見[交易指南](/hk/trading/info)。
