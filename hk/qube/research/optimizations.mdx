參數是可調整的數字，例如移動平均規則中的 20 天。調優會在保留研究想法的前提下，比較幾個選擇。

原來的設定稱為**基準組**。缺少這個比較，即使某個結果看起來吸引，也可能比原本更差。

## 選擇對應的調優方式

|          | 因子調優                                   | 策略調優                                          |
| -------- | ------------------------------------------ | ------------------------------------------------- |
| 主要問題 | 改變評分或分析設定，會否改善訊號關係？     | 改變規則中的數值，會否改善策略模擬結果？          |
| 例子     | 比較符合要求的均線回看天數或分組設定。     | 比較策略已使用的買入及賣出回看天數。              |
| 如何排名 | 平均 Rank IC，比較分數排名與之後收益排名。 | 總收益、夏普比率或最大回撤。                      |
| 另外檢查 | 使用整段研究期，需要另測其他期間。         | 預設 70% 研究、30% 驗證，在後段檢查研究段第一名。 |

## 有用的比較需要先訂計劃

執行前先決定基準組、候選選項、日期、適用的成本及比較指標。先從少量組合開始；搜尋越多，就越容易找到碰巧適合過去的設定。

之後同時檢查失敗、虧損及最高分。失敗候選沒有有效的成功結果，不能當作零收益。如果沒有有效候選，應修正研究設計，而不是硬選第一名。

## 套用是另一個決定

套用候選會改變已儲存的程式碼或設定。驗證改動，再跑一般分析或回測，通過檢查後建立命名版本。單獨套用不會開始這次一般測試，也不會送出交易。
