港股及美股因子支援以下 42 個平台算子。Python 使用 `factors` 欄位序列，公式使用大寫欄位名稱。輸入及結果須保留 `(date, symbol)` 索引；視窗按每個股票的觀測值計算，包含目前值。分組運算可能重排資料，組合前應按索引對齊。

## 橫截面與位移

| 算子 | 計算及邊界行為 |
| --- | --- |
| `RANK(X)` | 有 `date` 層時按每日股票升冪百分位排序，平手取平均，缺失填 0。沒有 `date` 層時對全序列排序。 |
| `DELAY(X,N)`、`REF(X,N)` | 同股票往前 N 筆，位移後缺失（包括來源缺失）填 0；正 N 回看，負 N 會讀取未來。 |
| `RETURNS(X,N)` | `X / DELAY(X,N) - 1`；歷史不足或分母零可能產生無限值或缺失。 |
| `PCT_CHANGE(X,N)` | 按股票執行 pandas `pct_change(N)`，缺失結果填 0；零分母仍可能產生無限值。 |
| `DIFF(X,N=1)` | 目前值減同股票 N 筆前的值，歷史不足保留缺失。 |

## 時間序列視窗

| 算子 | 計算及邊界行為 |
| --- | --- |
| `MA(X,N)`、`TS_MEAN(X,N)` | 同股票移動平均，不完整或無法計算的視窗填 0。 |
| `SUM(X,N)` | 移動加總，不完整或無法計算的視窗填 0。 |
| `TS_MIN(X,N)`、`TS_MAX(X,N)` | 移動最小／最大值，不完整視窗為缺失。 |
| `STD(X,N)`、`STDDEV(X,N)` | 樣本標準差，分母 N−1。不完整視窗或 N=1 為缺失；完整常數視窗（至少 2 筆）為 0。 |
| `VAR(X,N)` | 樣本變異數，分母 N−1，不完整視窗為缺失。 |
| `TS_SKEW(X,N)`、`TS_KURT(X,N)` | pandas 移動偏度／超額峰度，至少分別需 3／4 筆有效值，不完整視窗為缺失。 |
| `TS_RANK(X,N)` | 目前值在同股票最後 N 筆中的升冪百分位，平手取平均，不完整視窗為缺失。 |
| `TS_ARGMAX(X,N)`、`TS_ARGMIN(X,N)` | 極值位置從最舊 0 至目前 N−1；平手取最後一次，不完整視窗為缺失。 |
| `TS_ZSCORE(X,N)` | `(X-TS_MEAN(X,N))/STD(X,N)`；不完整為 NaN，標準差零可產生 NaN 或無限值。 |
| `SLOPE(X,N)` | 以位置 0 至 N−1 迴歸的斜率；不完整或少於 2 筆為 NaN。 |
| `COUNT(X,N)` | 用 SUM 計算條件為真的筆數，不完整視窗為 0。 |
| `EVERY(X,N)` | 視窗全部為真才回傳真；不完整為假。 |
| `EXIST(X,N)` | 至少一筆為真才回傳真；不完整為假。 |
| `LAST(X,N,M)` | 檢查 N 筆前至 M 筆前（含兩端）皆為真，要求 N \> M≥0；歷史不足為假，保留 symbol 層。 |
| `EMA(X,N)` | 每股票 `ewm(span=N, adjust=False)`，從第一筆有效觀測開始。 |
| `SMA(X,N,M=1)` | α=M/N，計算目前值×α＋前平均×(1−α)，選擇 0 \< M≤N，從第一筆開始遞迴。 |
| `WMA(X,N)` | 最舊至最新權重 1…N，除以權重總和；不完整或含缺失為缺失。 |

移動平均價差須用 `TS_MEAN(CLOSE,5)-TS_MEAN(CLOSE,20)`。`MEAN(CLOSE,5)-MEAN(CLOSE,20)` 會變成常數 −7.5，靜態驗證仍可能通過。依訊號定義遮罩不完整視窗。

## 雙序列、條件及逐元素運算

| 算子 | 計算及邊界行為 |
| --- | --- |
| `CORR(A,B,N)`、`CORRELATION(A,B,N)` | 同股票移動 Pearson 相關，不完整或常數視窗為缺失。 |
| `COVARIANCE(A,B,N)` | 移動樣本共變異數，不完整為缺失。 |
| `CROSS(X,Y)` | 目前 X\>Y 且前一筆 X≤Y；前值由 REF 提供並填 0，因此第一筆也可能判定交叉。需要真實交叉時排除歷史不足。 |
| `IF(X,A,B)` | 按條件 X 選 A 或 B，可用常數。序列分支須先對齊 X 的索引和順序；算子按位置選取並保留 X 索引。 |
| `ABS(X)`、`SIGN(X)`、`EXP(X)`、`LOG(X)` | 絕對值、符號、自然指數、自然對數；LOG 需正數，零或負值會產生無限值或缺失。 |
| `POWER(X,N)` | 逐元素 N 次方。 |
| `MIN(A,B)`、`MAX(A,B)` | 逐元素最小／最大值，可含常數；任一輸入缺失則缺失。移動極值須用 TS\_MIN／TS\_MAX。 |
| `MEAN(A,B)` | 逐元素 `(A+B)/2`，不是移動平均。 |
| `EQUAL(A,B)` | 逐元素相等比較，回傳布林序列。 |

CORR／CORRELATION／COVARIANCE 需相同索引；單股票時目前可能回傳單列 DataFrame。因子須回傳一維結果，先檢查形狀。

## 避免使用無對應執行函式的名稱

| 名稱 | 替代方式 |
| --- | --- |
| `DECAY_LINEAR` | 使用 `WMA(X,N)`。 |
| `SMA_CN`、`EMA_CN` | 依平滑權重選 `SMA(X,N,M=1)` 或 `EMA(X,N)`。 |
| `RET` | 使用 `RETURNS(X,N)` 或 `PCT_CHANGE(X,N)`，注意缺失行為不同。 |
| `FMIN`、`FMAX` | 使用逐元素 `MIN(A,B)`、`MAX(A,B)`。 |
| `VWAP(...)` | 市場提供時讀取 `factors["vwap"]` 或公式欄位 `VWAP`。 |

靜態驗證可接受的名稱不一定有執行函式。請以本頁支援清單為準。
