一次**執行**是一次因子分析或策略回測的嘗試。每次都會保留啟動時的程式碼與設定，以及狀態和結果。今天修改策略，不會改寫昨天的執行。

## 找到對應紀錄

開啟因子或策略，查看分析或回測歷史。先核對啟動時間、日期範圍及設定，確認正在閱讀哪一次實驗。

例如騰訊 20 日買入規則與 15 日買入規則，是兩個不同實驗。如果同時改了手續費，就不能從結果直接分辨有多少差異來自規則本身。

## 理解執行狀態

| 狀態                  | 代表什麼             | 應怎樣處理                   |
| --------------------- | -------------------- | ---------------------------- |
| 準備中（`preparing`） | 正在準備輸入。       | 稍後回到同一次執行。         |
| 排隊中（`queued`）    | 等候開始執行。       | 不要因為尚未開始就重複提交。 |
| 執行中（`running`）   | 正在計算。           | 已顯示圖表仍可能不完整。     |
| 成功（`succeeded`）   | 計算成功完成。       | 審閱輸入、結果及限制。       |
| 失敗（`failed`）      | 執行遇到問題而結束。 | 重試前先讀錯誤及日誌。       |
| 已取消（`cancelled`） | 執行已取消。         | 不能當作完整測試解讀。       |

要求停止後，可能仍需一段時間，應核對最終狀態。本機等待逾時不會取消遠端執行；如果要用 CLI 或 SDK 回來查看，請保留該次執行的識別碼。

## 在相同條件下比較

核對股票或股票池、日期、初始資金、成本、基準及規則。想解釋某個選擇的影響時，每次只改一項，再一起比較最後結果與途中虧損。

成功執行代表計算完成，不代表想法有利可圖或可靠。下結論前，請 Qube 解釋缺失數據、遭拒交易及異常期間。

## 保留或還原有用結果

命名版本保留成功一般執行的輸入。還原舊版本或執行時，會替換目前工作稿的輸入，不會改動舊結果，也不會自動開始新計算。重新執行前，先核對還原後的設定。

識別碼、結果分頁、不完整圖表、取消及還原命令等細節，見[執行 API](/hk/qube/api/runs)及 [SDK 進度指南](/hk/qube/sdk/streaming)。
