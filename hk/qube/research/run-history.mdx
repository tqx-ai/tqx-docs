每次分析或回測都有自己的 ObjectId，以及固定的原始碼、設定、市場、期間及選填因子綁定。目前資產的修改不會改寫歷史結果。

| 狀態 | 意義 |
| --- | --- |
| `preparing` | 正在準備輸入或執行環境。 |
| `queued` | 等待執行。 |
| `running` | 執行中。 |
| `succeeded` | 執行成功完成；請檢查可用結果。 |
| `failed` | 執行失敗；請檢查錯誤及日誌。 |
| `cancelled` | 執行已取消。 |

## 檢視及比較

從所屬資產或執行歷史開啟紀錄，確認原始碼／設定修訂、實際期間與設定、最終狀態、指標及日誌。比較條件一致的執行；成本或日期的改變可能與程式碼同樣重要。

資產庫及跨資產摘要使用不透明游標分頁。單一因子分析歷史回傳執行記錄，策略回測歷史則有筆數上限。回測結果欄位使用位移分頁。[CLI 執行操作](/hk/qube/api/runs) 及 [SDK API](/hk/qube/api/runs) 列出確切上限。

取消是請求，須確認最終狀態。輪詢逾時只會結束本機等待。保留執行 ID，方便再次讀取。

你可以從成功的一般執行建立命名版本，或將歷史執行輸入還原至目前資產。兩者都不會改寫舊執行，也不會提交新執行。
