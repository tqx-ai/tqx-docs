Skills 是可重用的指示，告訴 Qube 如何查詢數據、撰寫因子、撰寫策略、儲存知識或管理排程。要求 Agent 產生或執行程式碼前，先選擇符合任務的 Skill。

Qube 數據 Skill 提供原生歷史數據執行環境，不需要本機 API Key。因子及策略 Skill 的原始碼規約不同；因子注入的欄位與策略回測引擎 API 並不相同。

Skill 會改善 Agent 可用的指示，但不會跳過驗證、修訂保護、研究執行狀態或人工審閱。
