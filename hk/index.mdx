# 使用 TQX QUBE

無需編寫程式碼，即可探索策略、建立量化工作流程，並將研究成果轉化為可供審閱的交易決策。由交易構思開始，直至建立可運作的策略。

TQX QUBE 是一個以 AI 驅動的量化研究及交易工作流程設計平台。

你可以從市場假設、因子構思、研究文件、數據集、現有策略，或任何想要改進的工作流程開始。

加入所需的背景資料和工具，例如市場數據、研究檔案、Python 程式碼、風險限制、投資組合規則及執行要求。

## 由量化研究走向以證據為本的決策

下一代量化系統不會只圍繞單一模型、因子或交易訊號建立，而會建基於一套完整的研究及執行框架，連接以下各個環節：

- 市場及另類數據。
- 因子發掘及驗證。
- 策略設計及實作。
- 快速歷史回測。
- 投資組合構建及持倉規模設定。
- 參數優化及穩健性測試。
- 表現及風險評估。
- 流動性及交易成本控制。
- 人工審閱及授權。
- 券商連接及執行基礎設施。

QUBE 協助研究人員快速將初步構思轉化為可測試的策略及可量化的結果。與其反覆收集數據、編寫樣板程式碼、設定回測及計算表現指標，你可以要求 QUBE 在一個連貫的工作流程中整理並執行這些任務。

透過縮短研究及測試週期，QUBE 節省時間和精力，同時讓你比較不同方案、檢視假設、識別風險，並作出更明智、以證據為本的決策。
