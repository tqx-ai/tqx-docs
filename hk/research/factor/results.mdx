Qube 會把目前分析記錄、進度、參數和結果放在一起。使用結果時間選擇器切換歷史記錄。

## 先確認目標分組

因子方向決定哪一組代表訊號：

- **正向**：因子值最高的一組是目標組。
- **反向**：因子值最低的一組是目標組。

因子收益、Sharpe、年化收益和最大回撤都使用同一個方向目標組。不要假設分組表的第一行就是目標組。

## 查看關鍵指標

| 指標 | 含義 |
| --- | --- |
| 因子收益 | 按方向選出的分組或因子收益序列。 |
| Sharpe | 目標組相對於波動率的收益。 |
| 年化收益 | 期間表現的年化值。 |
| 最大回撤 | 目標組從高點到低點的最大跌幅。 |
| `IC_mean` | 因子值與之後收益之間的平均 Pearson 資訊係數。 |
| `Rank_IC` | 因子排序與之後收益之間的秩相關。 |
| `IC_std` | IC 觀測值的離散程度。 |
| `IC_IR` | IC 平均值相對於 IC 波動的比例。 |
| `IR` | 目標收益序列的資訊比率。 |
| `t-stat` | 觀察到的關係的統計強度。 |
| `P(IC<-0.02)` | IC 低於 -0.02 的觀測值比例。 |
| `P(IC>0.02)` | IC 高於 0.02 的觀測值比例。 |

沒有單一指標可以證明因子有效。請同時檢查方向、穩定性、樣本期間和經濟解釋。

## 閱讀圖表和表格

- **分組累計收益**：查看各組隨時間的表現。
- **分組收益表**：比較年化收益、超額收益、回撤、波動率、換手率、Sharpe 和資訊比率。
- **最新資料**：查看目標方向下最新的標的和因子值。
- **IC 和 Rank_IC 序列**：檢查預測能力是否持續。
- **IC 和 Rank_IC 分佈**：查看觀測值的分散程度和極端值。
- **IC 和 Rank_IC 衰減**：查看不同未來期間的關係變化。
- **IC 和 Rank_IC 自相關**：查看訊號是否持續或快速均值回歸。
- **3D 分組收益和超額收益**：比較分組差異隨時間的形狀。

<Warning>
歷史結果只代表某個程式碼版本、資料集、市場範圍和期間。將因子轉成策略前，請在較晚或獨立的期間重新驗證。
</Warning>
