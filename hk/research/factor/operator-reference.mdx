本頁列出 TQX 因子可使用的公式算子。欄位使用 `close`、`volume` 等小寫名稱，算子使用 `MA`、`RANK` 等大寫名稱。

<Warning>
因子公式會拒絕 `FUTURE_RETURNS(X, N)`，因為它會引入前視偏差。歷史收益請使用 `RETURNS(X, N)`。
</Warning>

## 數學算子

| 算子 | 表達式 | 說明 |
|---|---|---|
| `ABS` | `ABS(X)` | 絕對值 |
| `LOG` | `LOG(X)` | 自然對數 |
| `LOGABS` | `LOGABS(X)` | 絕對值的自然對數 |
| `AS_FLOAT` | `AS_FLOAT(X)` | 將布林序列轉換為 `0.0` 或 `1.0` |
| `RD` | `RD(X, N)` | 四捨五入至 `N` 位小數 |
| `SIGN` | `SIGN(X)` | 回傳 `-1`、`0` 或 `1` |
| `SIN` | `SIN(X)` | 正弦 |
| `COS` | `COS(X)` | 餘弦 |
| `TAN` | `TAN(X)` | 正切 |
| `ARCSIN` | `ARCSIN(X)` | 反正弦 |
| `ARCCOS` | `ARCCOS(X)` | 反餘弦 |
| `ARCTAN` | `ARCTAN(X)` | 反正切 |
| `POWER` | `POWER(X, N)` | `X` 的 `N` 次方 |
| `SIGNEDPOWER` | `SIGNEDPOWER(X, N)` | 保留正負號的次方運算 |

## 比較和條件算子

| 算子 | 表達式 | 說明 |
|---|---|---|
| `MAX` | `MAX(A, B)` | 逐元素取最大值 |
| `MIN` | `MIN(A, B)` | 逐元素取最小值 |
| `MEAN` | `MEAN(A, B)` | 逐元素取平均值 |
| `EQUAL` | `EQUAL(A, B)` | 逐元素判斷相等 |
| `VALUEWHEN` | `VALUEWHEN(A, B)` | 條件 `A` 為真時取 `B` |
| `CROSS` | `CROSS(X, Y)` | 判斷 `X` 是否上穿 `Y` |
| `LONGCROSS` | `LONGCROSS(A, B, N)` | `A` 連續低於 `B` `N` 期後上穿 |
| `LAST` | `LAST(X, N, M)` | 判斷 `X` 在 `N` 至 `M` 期是否都為真 |
| `IF` | `IF(X, A, B)` | `X` 為真取 `A`，否則取 `B` |

## 市場相容性

算子集合在不同市場共用，但可用欄位會依市場而變化：

| 市場 | 常用欄位 | 限制 |
|---|---|---|
| 港股 | `open`、`close`、`high`、`low`、`volume`、`amount`、`turnover`、`market_cap` | 只使用所選市場可用欄位 |
| 美股 | `open`、`close`、`high`、`low`、`volume`、`amount`、`turnover`、`market_cap` | 只使用所選市場可用欄位 |

## 範例

```text
RANK(close / DELAY(close, 20) - 1)
```

```text
(ZSCORE(oper_roe_ttm) + ZSCORE(-1 * ratio_pb_ttm)) / 2
```

```text
CORR(close, volume, 10)
```
