TQX 交易讓編程代理透過 TQX CLI 查詢帳戶、持倉、訂單、成交記錄和訊號，再下單、修改或撤單。Agent 也可以使用 `hold` 記錄活躍狀態，而不下達訂單。

你設定目標、帳戶權限和風險限制，Agent 可在此範圍內自主決策與執行，無須等待你逐筆批准訂單。請在 Agent 的指示中要求它持續評估證據、遵守風險限制；條件不足時，也可維持持倉或拒絕交易。

請先安裝 [TQX CLI](/hk/cli)。它可以從本地環境連接 TQX **仿真**帳戶或華泰**實盤**帳戶。

取得 API Key 後，登入並確認連線：

```bash
tqx login --api-key=<YOUR_API_KEY>
tqx status --json
tqx trading account --json
tqx trading positions --json
tqx trading hold --json
```

請參閱 [交易 API 參考](/hk/trading/api/place-order)，了解帳戶資料、持倉、`hold` 活躍狀態標記、訂單、成交記錄和訊號的 CLI 指令及 curl 請求。

<Warning>
  交易指令可能改變帳戶狀態。請設定 Agent
  在下單、修改或撤單前驗證市場、帳戶模式、標的、數量、價格和風險限制。**仿真**帳戶不涉及真實資金；**實盤**帳戶可能影響真實資金。
</Warning>
