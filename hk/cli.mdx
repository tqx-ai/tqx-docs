TQX CLI 讓 AI 編程代理在同一流程中串連投研與交易。Agent 使用 `tqx research` 管理 Qube 因子和策略，使用 `tqx trading` 查詢已連接帳戶，並在權限和風險限制內執行交易決策。

## 讓 Agent 幫你安裝

TQX Skills 協助編程代理使用 TQX CLI。點擊下方文字區塊右上角的複製按鈕，將完整提示詞貼到你的 Agent：

```text wrap
請讀取以下安裝指南：
https://github.com/tqx-ai/tqx-ts/blob/main/INSTALL.md

請依照指南安裝或更新 TQX CLI 的 Skills。識別你目前使用的 Agent，並使用該 Agent 的全域 Skills 目錄。檢查現有的 TQX CLI 安裝狀態，按指南需要安裝或更新 CLI。

請確認指南列出的所有 TQX Skills 均已安裝，且目前的 Agent 可以使用，並回報安裝路徑及驗證結果。
```

以上提示詞能讓你的 Agent 為你安裝好 TQX CLI 和 Skills。

## 手動安裝 CLI

<Tabs>
  <Tab title="獨立執行檔">
    從 [TQX Releases](https://github.com/tqx-ai/tqx-ts/releases) 下載目前平台的執行檔，將 `tqx` 放入 `PATH`，再確認版本：

    ```bash
    tqx --version
    ```

  </Tab>
  <Tab title="npm">
    需要 Node.js 22.18 或更新版本。

    ```bash
    npm install --global @tqx-ai/cli
    tqx --version
    ```

  </Tab>
  <Tab title="pnpm">
    ```bash
    pnpm add --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
  <Tab title="bun">
    ```bash
    bun add --global @tqx-ai/cli
    tqx --version
    ```
  </Tab>
</Tabs>

## 完成驗證

在 [TQX 帳戶中心](https://www.tqx.ai/hk/user-center?tab=ai-accounts) 建立 API Key，然後保存到 CLI 憑證儲存區：

```bash
tqx login --api-key=<YOUR_API_KEY>
tqx status --json
```

如需執行一次性指令，可以在該指令環境使用 `TQX_API_KEY`，而不保存 Key。不要將 Key 放入原始碼或公開記錄。
