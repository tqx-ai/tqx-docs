在自己的 Python 腳本或 Notebook 中使用 `tqx-data`，即可查詢港股與美股數據。你可以從 [PyPI](https://pypi.org/project/tqx-data/) 安裝套件，再以數據 API Key 完成驗證。

## 安裝

使用 Python 3.10 或更新版本：

```bash
python -m pip install --upgrade tqx-data
```

## 初始化

建立數據 [API Key](https://www.tqx.ai/user-center?tab=dev-settings)，在第一次查詢前初始化套件：

```python
import tqx_data

tqx_data.init(
    api_key="sk-tqx-...",
    base_url="https://tqxdata.tqx.ai",
)
```

也可以設定 `TQX_API_KEY` 與 `TQX_API_BASE_URL`，再呼叫 `tqx_data.init()`。請勿把 API Key 寫進原始碼或程式碼倉庫。

## 第一次查詢

初始化後，就可以在本機查詢股票詳情與交易日曆：

```python
stocks = tqx_data.get_stock_detail(
    symbol=["0700.HK"],
    market="hk",
    fields=["symbol", "name", "listed_date"],
)
calendar = tqx_data.get_trading_calendar(
    start_date="20250101",
    end_date="20250131",
    market="hk",
    is_trading_day=1,
    fields=["nature_date", "is_trade"],
)
print(stocks)
print(calendar)
```

兩次查詢都回傳 `pandas.DataFrame`。股票詳情包含指定的股票代碼和名稱；交易日曆包含所選市場及期間的交易日期。

## 方法

API 參考頁中的 <Badge color="green" icon="laptop">本機 tqx_data</Badge> 徽章表示該方法可在本機使用。

所有表格方法都回傳 `pandas.DataFrame`。回傳欄位由 `fields` 決定，並會 保留方法需要的識別欄位。下表列出支援的方法和入參。

| 方法 | 入參 | 回傳 |
| --- | --- | --- |
| `get_hk_daily` | `symbol`、`start_date`、`end_date`、`fields` | 港股日線資料 |
| `get_us_daily` | `symbol`、`start_date`、`end_date`、`fields` | 美股日線資料 |
| `get_stock_detail` | `symbol`、`market`、`status`、`fields` | 股票參考資料 |
| `get_trading_calendar` | `start_date`、`end_date`、`market`、`is_trading_day`、`fields` | 交易日與非交易日 |
| `get_currency` | `start_date`、`end_date`、`fields` | 匯率資料 |
| `get_event_devidend` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 股息與拆合股事件 |
| `get_event_capital_market` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 資本市場事件 |
| `get_event_corporate_actions` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 公司會議事件 |
| `get_event_fina_disclosure` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 財務揭露事件 |
| `get_event_investor_relation_activities` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 投資者關係事件 |
| `get_company_concentration` | `symbol`、`market`、`fields` | 投資人集中度 |
| `get_company_top_concentration` | `symbol`、`market`、`fields` | 前列投資人集中度 |
| `get_company_investor` | `symbol`、`market`、`fields`、`max_rank` | 投資人排行 |
| `get_company_insider_transaction` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 內部人交易 |
| `get_company_shareholder_report` | `symbol`、`market`、`fields`、`start_date`、`end_date` | 股東持股報告 |
| `get_company_price_vol` | `symbol`、`market`、`fields` | 公司價量指標 |
| `get_company_oper_metrics` | `symbol`、`market`、`fields`、`start_year`、`end_year` | 營運指標 |
| `get_company_current` | `symbol`、`market`、`fields` | 公司最新指標 |
| `get_company_imed` | `symbol`、`market`、`fields` | 行業中位指標 |
| `get_consensus_nonperiod` | `symbol`、`market`、`fields` | 非週期一致預期 |
| `get_consensus_recommend` | `symbol`、`market`、`fields` | 買賣建議一致預期 |
| `get_financial_statement` | `start_quarter`、`end_quarter`、`symbol`、`fields`、`market`、`date`、`is_latest`、`interim_type` | 財務報表資料 |

合併方法使用 `market="hk"` 查詢港股，使用 `market="us"` 查詢美股，財務報表方法亦然。`market` 省略時預設為 `hk`。日期使用 `YYYYMMDD`，財務季度使用 `YYYYqN`。

## 與 Qube 的差異

本機套件與 Qube 都使用 `import tqx_data`。股票詳情、交易日曆、日線、事件、公司指標、一致預期、財務報表和匯率在兩個環境都可用，但初始化方式、必填參數和可用欄位可能不同。

| 方法或功能 | Qube | 本機套件 |
| --- | --- | --- |
| 初始化 | 不需要本機 API Key | 以數據 API Key 呼叫 `tqx_data.init(...)` |
| 查詢日線 | `get_hk_daily`、`get_us_daily` | 方法相同；須提供起訖日期，期間不超過五年 |
| 查詢股票詳情或日曆 | `get_stock_detail`、`get_trading_calendar`；`market="hk"` 或 `"us"` | 方法及市場代碼相同，須先初始化 |
| 查詢財務報表 | `market` 必填，使用 `hk` 或 `us` | `market` 選填，預設 `hk`；美股使用 `us` |
| 查詢歷史分鐘線 | `get_hk_min`、`get_us_min` | 不提供這兩個方法 |
| 查詢因子欄位、公告或指數成分 | `get_factor`、`get_filing_announcement`、`get_index_component` | 不提供這些方法 |
| 訂閱 Tick 訊息 | 未提供 `TickStreamClient` | `TickStreamClient` |

本站的 API 頁面會標示支援環境。日線查詢必須提供 `start_date` 和 `end_date`，且起訖日期跨度不得超過五年；詳見 [日線參數](/hk/data/market-data/daily)。財務報表的 `market` 可省略，預設為 `hk`；詳見 [財務報表參數](/hk/data/financial-and-market-factors/financial-statements)。

## 交易日曆輔助函式

以下函式在初始化後使用。`market` 可選 `hk` 或 `us`，預設為 `hk`。

| 函式 | 輸入 | 回傳 |
| --- | --- | --- |
| `get_prev_trade_date(date, market="hk", n=1)` | `date` 必填，格式為 `YYYYMMDD`；`n` 為正整數，預設 `1` | 指定日期之前第 `n` 個交易日，型別為 `str`；無結果時為 `None` |
| `get_last_trade_date(market="hk")` | `market` 選填 | 最新交易日，型別為 `str`；無結果時為 `None` |
| `get_trade_list(date, market="hk")` | `date` 必填，可傳日期字串或日期清單 | 指定日期的可交易股票，型別為 `pandas.DataFrame` |

## 認證狀態

這些函式用來檢查或清除本機認證狀態。它們不會向服務端驗證 API Key 的權限。

| 函式 | 輸入 | 回傳與用途 |
| --- | --- | --- |
| `is_authenticated()` | 無 | `bool`，表示本機是否已設定 API Key 或有有效認證狀態 |
| `auth_remaining_seconds()` | 無 | `float`；API Key 模式為 `float("inf")`，未認證時為 `0.0` |
| `auth_expires_at()` | 無 | 到期時間的 Unix 時間戳記或 `None`；API Key 模式為 `None` |
| `auth_info()` | 無 | `dict`，包含認證狀態、剩餘秒數和到期時間，不包含 API Key |
| `clear_auth()` | 無 | 清除本機認證狀態，回傳 `None`；不會撤銷服務端的 API Key |

## TickStreamClient

`TickStreamClient` 透過 WebSocket 傳送即時 Tick 訊息。建構時必須指定 `market="HK"` 或 `market="US"`；港股使用 `.HK`，美股使用 `AAPL` 等不帶後綴的代號。

```python
from tqx_data import TickStreamClient

client = TickStreamClient(market="HK")
client.subscribe_tick(["0700.HK"])
client.listen(handler=print)
```

公開控制方法包括 `subscribe_tick`、`unsubscribe_tick`、`listen`、`close`、 `subscribed_symbols`、`is_running` 和 `get_stats`。
