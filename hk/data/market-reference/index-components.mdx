### 回應參數

| 字段 | 類型 | 描述 |
|:-------------|:-----|:---------------|
| index_symbol | str | 指數碼 |
| stock_symbol | str | 股票代號 |
| added_date | str | 納入成分股日期 |
| deleted_date | str | 剔除成分股日期 |

### 使用範例

#### 取得全部港股指數成分股信息

```python
import tqx_data
result = tqx_data.get_index_component(
    market='hk',
    stock_symbol="",
    index_symbol="",
)
print(result)
```
