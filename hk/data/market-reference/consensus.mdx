## 取得非週期性指標一致預期

### 方法名稱：get\_consensus\_nonperiod

<Badge stroke icon="clock">僅提供最新數據</Badge>

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
| :-- | :-- | :-- | :-- |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 傳回欄位 | 非必填 |
| market | str | 市場，使用 `hk` 或 `us`，預設為 `hk`。 | 非必填 |

### 回應參數

沒有時間後綴的欄位，表示目前可用的最新預測。歷史預測欄位會加上後綴，表示該預測是在多久以前作出的：

| 後綴 | 含義 |
| --- | --- |
| （無） | 目前可用的最新預測 |
| `_week` | 一週前的預測 |
| `_1month` 至 `_12month` | 一至十二個月前的預測 |

例如，`mean_week` 是一週前的預測平均值，`std_6month` 是六個月前的預測標準差。`symbol`、`currency` 和 `indicator` 只是識別資料列，不使用這些時間後綴。

| 字段 | 類型 | 描述 |
| :-- | :-- | :-- |
| symbol | str | 檔 |
| currency | str | 貨幣單位 |
| indicator | str | 指標名稱:LTGROWTH 為未來 3~5 年長期成長，TP 為未來 1 年目標價 |
| mean | double | 預測平均值 |
| median | double | 預測中位數 |
| high | double | 預測最高值 |
| low | double | 預測最低值 |
| std | double | 預測標準差 |
| estimates\_num | double | 預測數 |
| included\_estimates\_num | double | 納入統計的預測數 |

### 使用範例

#### 取得全港股非週期性指標的部分一致預期

```python
import tqx_data
result = tqx_data.get_consensus_nonperiod(
    market='hk',
    symbol=[""],
    fields=["indicator","mean","std_6month","high_week"]
)
print(result)
```

## 取得買賣建議一致預期

### 方法名稱：get\_consensus\_recommend

<Badge stroke icon="clock">僅提供最新數據</Badge>

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
| :-- | :-- | :-- | :-- |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 傳回欄位 | 非必填 |
| market | str | 市場，使用 `hk` 或 `us`，預設為 `hk`。 | 非必填 |

### 回應參數

沒有時間後綴的欄位，表示目前可用的最新建議。歷史欄位使用相同的後綴：

| 後綴 | 含義 |
| --- | --- |
| （無） | 目前可用的最新建議 |
| `_week` | 一週前的建議 |
| `_1month` 至 `_12month` | 一至十二個月前的建議 |

例如，`mean_week` 是一週前的預期平均值，`low_6month` 是六個月前的預期最低值。建議數量使用以下分數：強力賣出 = 5、賣出 = 4、持有 = 3、買入 = 2、強力買入 = 1。

| 字段 | 類型 | 描述 |
| :-- | :-- | :-- |
| symbol | str | 檔 |
| currency | str | 貨幣單位 |
| mean | double | 預期平均數 |
| median | double | 預期中位數 |
| high | double | 預期最高值 |
| low | double | 預期最低值 |
| strong\_buy\_num | double | 強買建議數 |
| buy\_num | double | 買進建議數 |
| hold | double | 持倉建議數 |
| sell\_num | double | 賣出建議數 |
| strong\_sell\_num | double | 強賣建議數 |
| no\_opinion\_num | double | 無意見數 |
| recommendations\_num | double | 推薦總數 |

### 使用範例

#### 取得全港股買賣建議的部分一致預期

```python
import tqx_data
result = tqx_data.get_consensus_recommend(
    market='hk',
    symbol=[""],
    fields=["strong_buy_num","buy_num_week"]
)
print(result)
```
