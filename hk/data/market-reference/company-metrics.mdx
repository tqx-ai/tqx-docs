### 14. 取得公司標準化營運指標

#### 14.1. 方法名稱：get_company_oper_metrics

#### 14.2. 入參

| 欄位 | 類型 | 說明 | 是否必填 |
|:---|:---|:---|:---|
| start_year | str | 開始財政年度,eg:"2025" | 必填 |
| end_year | str | 結束財政年度,eg:"2025" | 必填 |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 傳回欄位 | 非必填 |
| market | str | 市場，支持"hk" ,"us"，預設為"hk" | 必填 |

#### 14.3. 回應參數

| 字段 | 類型 | 描述 |
|:--------------------------|:-------|:----------------------|
| symbol | str | 檔 |
| is_final | int | 是否是最終報告 |
| financial_year | str | 財政年度 |
| financial_period_end_date | str | 財報截止日期 |
| report_type | str | 報告類型（原始/重述） |
| data_type | str | 資料型別 |
| consol_basis | str | 資料合併基礎 |
| report_source | str | 報告來源 |
| item_name | str | 指標名稱 |
| is_pershare_item | str | 是否為每股指標 |
| is_percent_item | str | 是否為百分比指標 |
| item_unit | str | 指標單位縮放 |
| item_currency | str | 指標貨幣單位 |
| item_num | double | 指標值 |

#### 14.4. 使用範例

##### 14.4.1. 取得某財政年度全部港股公司標準化營運指標

```python
import tqx_data
result = tqx_data.get_company_oper_metrics(
    market='hk',
    symbol=[""],
    fields=[""],
    start_year="2023",
    end_year="2025",
)
print(result)
```
