## 取得股票股利相關的事件

### 方法名稱：get_event_devidend

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
|:---|:---|:---|:---|
| start_date | str | 開始日期,eg:"20250702" | 必填 |
| end_date | str | 結束日期,eg:"20250702" | 必填 |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 傳回欄位 | 非必填 |
| market | str | 市場，支持"hk" ,"us"，預設為"hk" | 必填 |

### 回應參數

| 字段 | 類型 | 描述 |
|:-------------|:-----|:---------------------------------|
| publish_date | str | 活動公告發佈日期（日期篩選依據） |
| symbol | str | 檔 |
| excute_date | str | 事件執行日期 |
| event_type | str | 事件類型 |
| number | str | 每股金額 |
| currency | str | 交易幣種 |
| event | str | 事件 |

### 使用範例

#### 取得某一港股分紅在一定時間內股股相關的事件

```python
import tqx_data
result = tqx_data.get_event_devidend(
    market='hk',
    symbol="9999.HK",
    fields=[],
    start_date="20250101",
    end_date="20260501",
)
print(result)
```
