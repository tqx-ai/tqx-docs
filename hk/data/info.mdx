TQX 提供港股與美股的行情、參考、財務與市場因子資料。股票代碼使用市場後綴：港股為 `.HK`（例如 `0001.HK`、`0700.HK`），美股 NASDAQ BASIC 為 `.NB`（例如 `AAPL.NB`、`0013.NB`）。

## 安裝 tqx_data

你可以從 [PyPI](https://pypi.org/project/tqx-data/) 下載 `tqx-data` 套件：

```bash
pip install tqx-data
```

<Note>
  目前使用 `tqx_data` 需要 TQX 數據帳號。請聯絡 Audrey（[audrey@tqx.trade](mailto:audrey@tqx.trade)）開通權限。
</Note>

<Warning>
  本文件中的方法以 Qube 內建的 `tqx_data` 為準。PyPI 上的 `tqx-data` 套件正在更新，新版發布前，部分方法名稱與參數可能與文件不一致。
</Warning>
