TQX 為港股及美股研究提供歷史行情、市場參考、財務及因子數據。複製 API 範例前，先選擇執行環境。

## 適用環境

Tag 標示方法或範例支援的環境；多個 tag 代表可在各標示環境使用。

| Tag                                                    | 使用方式                                                                      |
| ------------------------------------------------------ | ------------------------------------------------------------------------- |
| <Badge color="purple" icon="code">策略原始碼</Badge>        | 使用對應市場的 `panda_backtest` API。[策略程式碼中的 API](/hk/qube/research/strategy/api)。 |
| <Badge color="blue" icon="cloud">Qube 沙箱</Badge>       | 使用內建的 `tqx_data`，無須本機初始化。[Qube 沙箱指南](/hk/data/qube-runtime)。              |
| <Badge color="green" icon="laptop">本機 tqx_data</Badge> | 安裝 `tqx-data`，並以數據 API Key 初始化。[本機指南](/hk/data/local-package)。            |

因子程式碼使用框架提供的輸入數據，詳見 [編寫因子](/hk/qube/research/factor/code)。

## 代碼及可用範圍

港股數據使用例如 `0700.HK` 的代碼。Qube 原生 `tqx_data` 的美股歷史行情、市場參考、財務與因子查詢統一使用不帶後綴的代碼，例如 `AAPL`；回傳的 `symbol` 和 `stock_symbol` 亦不帶後綴。需要選擇市場時，使用 `market="us"` 或因子查詢的 `type="us"`。

美股策略引擎使用 `AAPL.NB` 等代碼；策略程式碼請依照 [編寫策略](/hk/qube/research/strategy/code) 使用對應格式。

本站的 Qube 數據範例查詢歷史快照；即時訂閱請參閱 [本機 Tick 串流](/hk/data/market-data/tick)。請驗證涵蓋範圍、缺失欄位、時區、復權行為及公告日期。歷史財務值必須在決策當時已經公開。
