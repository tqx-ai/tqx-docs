## 取得貨幣資料

### 方法名稱：get\_currency

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
| :-- | :-- | :-- | :-- |
| start\_date | Optional\[str\] | 開始日期,eg:"20250702" | 非必填 |
| end\_date | Optional\[str\] | 結束日期,eg:"20250702" | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 匯率清單 | 非必填 |

### 使用範例

#### 取得單一港股的部分回測因子

```python
import tqx_data
result = tqx_data.get_currency(
    start_date="20260101",
    end_date="20260131",
    field=[],
)
print(result)
```
