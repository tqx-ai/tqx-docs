## 取得貨幣資料

### 方法名稱：get_currency

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
|:---|:---|:---|:---|
| start_date | Optional\[str\] | 開始日期,eg:"20250702" | 非必填 |
| end_date | Optional\[str\] | 結束日期,eg:"20250702" | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 匯率清單 | 非必填 |

### 回應參數

| 字段 | 類型 | 描述 |
|:--------|:-------|:-------------|
| date | str | 日期 |
| CNY_HKD | double | 人民幣對港幣 |
| CNY_USD | double | 人民幣對美元 |
| HKD_USD | double | 港幣對美元 |
| HKD_CNY | double | 港幣對人民幣 |
| USD_CNY | double | 美元對人民幣 |
| USD_HKD | double | 美元對港幣 |

### 使用範例

#### 取得單一港股的部分回測因子

```python
import tqx_data
result = tqx_data.get_currency(
    start_date="20260101",
    end_date="20260131",
    field=[],
)
print(result)
```
