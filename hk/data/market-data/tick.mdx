#### 6.1. 方法名稱：get_tick_data

#### 6.2. 入參

| 字段 | 類型 | 描述 |
|:---|:---|:---|
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 |
| market | Optional\[str\] | 市場，預設為‘hk’, 可選‘hk’，‘nb’ |

#### 6.3. 回應參數

| 字段 | 類型 | 描述 |
|:-------------|:-------|:---------------|
| date | str | 日期與時間 |
| symbol | str | 檔 |
| last_price | double | 最新價 |
| price_change | double | 價格變動 |
| percentage | double | 價格百分比變化 |

#### 6.4. 使用範例

##### 6.4.1. 取得1檔股票的最新tick數據

```python
import tqx_data
result = tqx_data.get_tick_data(
    symbol=["0700.HK"],
    market="hk",
)
print(result)
```

**回應範例**

```text
symbol last_price date
0 0700.HK 516.0 2026-03-24 15:59:59.000
```
