## 取得港股分鐘線數據

### 方法名稱：get_hk_min

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
|:---|:---|:---|:---|
| start_date | str | 開始日期,eg:"20250702" | 必填 |
| end_date | str | 結束日期,eg:"20250702" | 必填 |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號, 當symbol為空時，開始與結束日期不能超過1個月 | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 返回欄位,如果不傳,預設為 "open","high", "low","close","volume"和"amount" | 非必填 |
| time_zone | Optional\[tuple\] | 時段過濾,格式為("HH:MM", "HH:MM")，例如("10:00", "23:00") | 非必填 |
| frequency | Optional\[str\] | 頻率, 支援 "1m", "5m", "10m", "60m",預設為"1m" | 非必填 |

### 回應參數

| 字段 | 類型 | 描述 |
|:-----------|:-------|:---------------------|
| date | str | 日期 |
| datetime | str | 日期與時間 |
| minute | str | 時間（精準至分） |
| symbol | str | 檔 |
| open | double | 分鐘開盤價 |
| high | double | 分鐘最高價 |
| low | double | 分鐘最低價 |
| close | double | 分鐘收盤價 |
| volume | double | 分鐘成交量 |
| amount | double | 分鐘成交金額 |
| num_trades | double | 分鐘成交筆數 |
| high_yld | double | 分鐘最高收益率 |
| low_yld | double | 分鐘最低收益率 |
| open_yld | double | 分鐘開盤收益率 |
| yield | double | 分鐘收盤收益率 |
| vwap | double | 分鐘成交量加權平均價 |
| bid_high | double | 買盤最高優惠 |
| bid_low | double | 買盤最低報價 |
| open_bid | double | 開盤買盤價 |
| bid | double | 收盤買盤價 |
| bid_nummov | double | 買盤變動次數 |
| ask_high | double | 賣盤最高報價 |
| ask_low | double | 賣盤最低報價 |
| open_ask | double | 開盤賣價 |
| ask | double | 收盤賣盤價 |
| ask_nummov | double | 賣盤變動次數 |
| mid_high | double | 中間價最高值 |
| mid_low | double | 中間價最低值 |
| mid_open | double | 開盤中間價 |
| mid_price | double | 收盤中間價 |

### 使用範例

#### 取得單一股票的1分鐘線資料並使用fields

```python
import tqx_data
result = tqx_data.get_hk_min(
    symbol="0700.HK",
    start_date="20260101",
    end_date="20260131",
    fields=["symbol", "date", "num_trades", "amount", "volume"],
    frequency="1m",
    time_zone=("10:00", "11:00")
)
print(result)
```
