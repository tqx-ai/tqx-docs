### 1. 取得港股日線數據

#### 1.1. 方法名稱：get_hk_daily

#### 1.2. 入參

| 欄位 | 類型 | 說明 | 是否必填 |
|:---|:---|:---|:---|
| start_date | str | 開始日期,eg:"20250702"，與結束日期間不超過5年 | 必填 |
| end_date | str | 結束日期,eg:"20250702"，與開始日期間不超過5年 | 必填 |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 | 非必填 |
| fields | Optional\[Union\[str, List\[str\]\]\] | 傳回欄位 | 非必填 |

#### 1.3. 回應參數

| 字段 | 類型 | 描述 |
|:-------------|:-------|:----------------------|
| date | str | 交易日 |
| symbol | str | 檔 |
| open | str | 開盤價 |
| high | double | 最高價 |
| low | double | 最低價 |
| close | double | 理論收市價 |
| volume | double | 成交量 |
| pre_close | double | 前一日收盤價 |
| name | str | 股票名稱 |
| trade_status | int | 交易狀態代碼 |
| alt_close | double | 調整收市價（同close） |
| acvol_uns | double | 成交股數（同volume） |
| bid | double | 買盤價 |
| ask | double | 賣盤價 |
| vwap | double | 成交量加權平均價 |
| vwap_vol | double | 計算VWAP的成交量 |
| opn_aucvol | double | 開市競價時段交易量 |
| opn_auc | double | 開市競價時段價格 |
| lmt_refpr2 | double | 限價參考價 |
| lolimit | double | 價格下限 |
| uplimit | double | 價格上限 |
| lolimit_2 | double | 二級價格下限 |
| uplimit_2 | double | 二級價格上限 |
| navalue | double | 淨值 |
| num_moves | double | 成交筆數 |
| uplimit_3 | double | 三級價格上限 |
| lolimit_3 | double | 三級價格下限 |
| cls_aucvol | double | 收市競價時段成交量 |

#### 1.4. 使用範例

##### 1.4.1. 取得某日期內所有港股的日線數據

```python
import tqx_data
result = tqx_data.get_hk_daily(
    symbol=[],
    start_date="20250101",
    end_date="20250131",
    fields=[]
)
print(result)
```

### 2. 取得美股日線數據

#### 2.1. 方法名稱：get_us_daily

#### 2.2. 入參
