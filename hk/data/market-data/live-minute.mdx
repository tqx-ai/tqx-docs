`TickStreamClient` 透過 WebSocket 持續接收港股或美股的即時 Tick 訊息，適合在自己的 Python 程式中監察行情或處理串流數據。

## 安裝與初始化

使用 Python 3.10 或更新版本安裝套件：

```bash
python -m pip install --upgrade tqx-data
```

在 [開發者設定](https://www.tqx.ai/user-center?tab=dev-settings) 建立數據 API Key，將下方的 `sk-tqx-...` 換成你的 Key：

```python
import tqx_data
from tqx_data import TickStreamClient

tqx_data.init(
    api_key="sk-tqx-...",
    base_url="https://tqxdata.tqx.ai",
)
```

`TickStreamClient` 會沿用初始化時的 API Key，並自動選擇對應市場的 WebSocket 地址。

## 訂閱即時行情

執行上方初始化後，選擇一個市場。以下範例持續列印收到的訊息，30 秒後關閉連線。

<Tabs>
  <Tab title="港股">
    ```python
    import time
    
    client = TickStreamClient(market="HK")
    client.subscribe_tick(["0700.HK", "0005.HK"])
    
    try:
        client.listen(handler=print)
        time.sleep(30)
    finally:
        client.close()
    ```
  </Tab>
  <Tab title="美股">
    ```python
    import time
    
    client = TickStreamClient(market="US")
    client.subscribe_tick(["AAPL", "TSLA"])
    
    try:
        client.listen(handler=print)
        time.sleep(30)
    finally:
        client.close()
    ```
  </Tab>
</Tabs>

| 設定 | 港股 | 美股 |
| --- | --- | --- |
| `market` | `"HK"` | `"US"` |
| 股票代號 | `0700.HK`、`0005.HK` | `AAPL`、`TSLA`，不加後綴 |

一個客戶端只能訂閱一個市場。同時接收港股與美股時，請分別建立兩個客戶端。

## Tick 與分鐘 K 線

Tick 是持續推送的即時訊息；分鐘 K 線則是把一分鐘內的數據彙整成開市價、最高價、最低價與收市價。`TickStreamClient` 接收的是 Tick 訊息，沒有直接回傳分鐘 K 線的方法。若需要分鐘 K 線，請在自己的程式中按標的及時間彙整。
