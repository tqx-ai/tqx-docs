## 取得港美股回測因子

### 方法名稱：get_factor

### 入參

| 欄位 | 類型 | 說明 | 是否必填 |
|:---|:---|:---|:---|
| start_date | str | 開始日期,eg:"20250702" | 必填 |
| end_date | str | 結束日期,eg:"20250702" | 必填 |
| symbol | Optional\[Union\[str, List\[str\]\]\] | 股票代號 | 非必填 |
| factors | Union\[str, List\[str\]\] | 因子列表 | 必填 |
| type | Optional\[str\] | 產品類型，支援"hk" ,"nb"，預設為"hk" | 非必填 |

### 回應參數

基礎因子類:

| 字段 | 類型 | 描述 |
|:----------|:-------|:-----------|
| date | str | 日期 |
| symbol | str | 檔 |
| open | double | 開盤價 |
| close | double | 收盤價 |
| high | double | 最高價 |
| low | double | 最低價 |
| volume | double | 成交量 |
| amount | double | 成交額 |
| pre_close | double | 前日收盤價 |

### 使用範例

#### 取得單一港股的部分回測因子

```python
import tqx_data
result = tqx_data.get_factor(
    symbol="0700.HK",
    start_date="20260101",
    end_date="20260131",
    type="hk",
    factors=["symbol", "date", "close"],
)
print(result)
```
