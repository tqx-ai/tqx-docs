TQX provides Hong Kong and US historical market, reference, financial, and factor data for research. Choose the environment before copying an API example.

## Choose the runtime

<Tabs>
  <Tab title="Qube runtime">
    In the Qube sandbox, native `tqx_data` uses platform-provided historical data. Do not initialize it with a local API key. Read [Access data in Qube](/data/qube-runtime) before using the reference pages below.

    For data access inside a strategy, follow [Write a strategy](/qube/research/strategy/code). Factor code receives its inputs from Qube; see [Write a factor](/qube/research/factor/code).

  </Tab>
  <Tab title="Local PyPI package">
    Install `tqx-data` in your own Python environment and initialize with a data API key and service address. Follow [Local package](/data/local-package) for installation, methods, fields, and Tick streaming. This contract differs from Qube.
  </Tab>
</Tabs>

## Symbols and availability

Hong Kong data uses symbols such as `0700.HK`. Qube native `tqx_data` queries for US historical prices, market reference, financial statements, and factors use bare symbols such as `AAPL`. Returned `symbol` and `stock_symbol` columns also use bare symbols. When selecting the market, use `market="us"` or `type="us"` for factor queries.

The US strategy engine uses symbols such as `AAPL.US`. Follow [Write a strategy](/qube/research/strategy/code) for the format used in strategy code.

The Qube data examples here query historical snapshots. For live subscriptions, see [Local Tick streaming](/data/market-data/tick). Verify coverage, missing fields, timezones, adjustment behavior, and announcement dates. Historical financial values must have been available at the decision time.
