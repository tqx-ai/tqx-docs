---
title: "TQX data"
description: "Market and reference data available through tqx_data."
---

TQX provides market, reference, financial, and market-factor data for Hong Kong and US stocks. Use a market suffix in each symbol: `.HK` for Hong Kong stocks (for example, `0001.HK` and `0700.HK`) and `.NB` for NASDAQ BASIC stocks (for example, `AAPL.NB` and `0013.NB`).

## Install tqx_data

Download the `tqx-data` package from [PyPI](https://pypi.org/project/tqx-data/):

```bash
pip install tqx-data
```

<Note>
  You currently need a TQX data account to use `tqx_data`. Contact Audrey at [audrey@tqx.trade](mailto:audrey@tqx.trade) to get access.
</Note>

<Warning>
  The methods on these pages follow the `tqx_data` built into Qube. The `tqx-data` package on PyPI is being updated, so some method names and parameters may differ until the new version is released.
</Warning>
