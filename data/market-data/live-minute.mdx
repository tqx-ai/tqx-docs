`TickStreamClient` receives live Hong Kong or US stock ticks over WebSocket. Use it in your own Python process to monitor prices or process streaming data.

## Install and initialize

Install the package with Python 3.10 or later:

```bash
python -m pip install --upgrade tqx-data
```

Create a data API key in [developer settings](https://www.tqx.ai/user-center?tab=dev-settings), then replace `sk-tqx-...` below with your key:

```python
import tqx_data
from tqx_data import TickStreamClient

tqx_data.init(
    api_key="sk-tqx-...",
    base_url="https://tqxdata.tqx.ai",
)
```

`TickStreamClient` uses the initialized API key and automatically selects the WebSocket address for your market.

## Subscribe to live data

After initialization, choose a market. These examples print incoming messages for 30 seconds, then close the connection.

<Tabs>
  <Tab title="Hong Kong">
    ```python
    import time
    
    client = TickStreamClient(market="HK")
    client.subscribe_tick(["0700.HK", "0005.HK"])
    
    try:
        client.listen(handler=print)
        time.sleep(30)
    finally:
        client.close()
    ```
  </Tab>
  <Tab title="US">
    ```python
    import time
    
    client = TickStreamClient(market="US")
    client.subscribe_tick(["AAPL", "TSLA"])
    
    try:
        client.listen(handler=print)
        time.sleep(30)
    finally:
        client.close()
    ```
  </Tab>
</Tabs>

| Setting | Hong Kong | US |
| --- | --- | --- |
| `market` | `"HK"` | `"US"` |
| Symbols | `0700.HK`, `0005.HK` | `AAPL`, `TSLA`, without a suffix |

Each client subscribes to one market. Create separate clients to receive both Hong Kong and US data.

## Ticks and minute bars

Ticks arrive as live messages. A minute bar aggregates data within a minute into an open, high, low, and close. `TickStreamClient` receives ticks and has no method that returns minute bars directly. To build minute bars, aggregate the messages by symbol and time in your own code.

Continue to [Tick data](/data/market-data/tick) for callbacks, subscription management, and parameters.
