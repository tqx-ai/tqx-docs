## What is a Tick?

A Tick is one small update from the market. It may record a trade, a quote change, or another piece of live market information. If you watch a stock during the trading day, you may receive many Tick updates for the same symbol.

A minute bar combines many updates into one summary for a minute. Tick data keeps the updates separate, so it is useful when you need to react as the market changes. It also means that messages arrive continuously and may not have a fixed interval.

Use `TickStreamClient` to subscribe to live market data. Provide stock symbols and a message handler; the client delivers incoming <Tooltip tip="WebSocket is a connection that stays open between your program and the data service, so the service can push new messages to you as they arrive. You do not need to send a new request for every update." headline="WebSocket">WebSocket</Tooltip> messages to that function.

## Start a subscription

Install the package:

```bash
python -m pip install --upgrade tqx-data
```

Create a data API key in [developer settings](https://www.tqx.ai/user-center?tab=dev-settings) and replace `sk-tqx-...` below. This example receives Hong Kong messages for 30 seconds, then closes the connection.

```python
import time
import tqx_data
from tqx_data import TickStreamClient

tqx_data.init(
    api_key="sk-tqx-...",
    base_url="https://tqxdata.tqx.ai",
)

def on_message(message):
    print(message)

client = TickStreamClient(market="HK")
client.subscribe_tick(["0700.HK", "0005.HK"])

try:
    client.listen(handler=on_message)
    time.sleep(30)
finally:
    client.close()
```

For US stocks, use `market="US"` and bare symbols such as `AAPL` or `TSLA`. Each client subscribes to one market.

## Constructor parameters

After `tqx_data.init(...)`, you only need to provide `market` to create a client. Use these parameters to adjust message delivery:

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `market` | `str` | Required | `"HK"` or `"US"` |
| `heartbeat_interval` | `int` | `30` | Heartbeat interval in seconds |
| `reconnect_interval` | `float` | `3.0` | Seconds to wait before reconnecting |
| `max_reconnect_attempts` | `int` | `0` | Maximum reconnection attempts; `0` means unlimited |
| `parse_json` | `bool` | `True` | Parse JSON messages; `False` delivers raw strings |
| `batch_callback` | `bool` | `False` | Deliver a list of messages per callback when `True` |
| `handler_batch_size` | `int` | `1000` | Maximum messages per batch |
| `handler_batch_timeout` | `float` | `0.01` | Maximum batch wait in seconds |

## Methods and return values

| Method or property | Input | Returns | Purpose |
| --- | --- | --- | --- |
| `subscribe_tick(symbols)` | A symbol string or list of strings | `None` | Add subscriptions |
| `unsubscribe_tick(symbols)` | A symbol string or list of strings | `None` | Remove specific subscriptions while keeping others active |
| `listen(handler=None, block=False)` | Message handler and whether to block the current thread | `None` | Start receiving; print messages when no handler is provided |
| `close()` | None | `None` | Close the connection and stop receiving |
| `subscribed_symbols` | Property; no parentheses | `set[str]` | Currently subscribed symbols |
| `is_running` | Property; no parentheses | `bool` | Whether the client is running |
| `get_stats()` | None | `dict` | Received, processed, and dropped counts, plus throughput |

`listen` runs in the background by default. The example uses `time.sleep(30)` to keep the process alive. To keep receiving on the current thread, use `listen(handler=on_message, block=True)`.

## Handle incoming messages

By default, the handler receives one message at a time. JSON messages are parsed; content that cannot be parsed stays a raw string. Messages can include subscription confirmations as well as market data. Print the messages to inspect their fields before adding your processing logic.

For batch processing, set `batch_callback=True`. The handler then receives a list:

```python
def on_batch(messages):
    for message in messages:
        print(message)

client = TickStreamClient(market="HK", batch_callback=True)
client.subscribe_tick("0700.HK")

try:
    client.listen(handler=on_batch)
    time.sleep(30)
finally:
    client.close()
```

This uses the imports and initialization from the first example. To change subscriptions, call `client.subscribe_tick("0005.HK")` to add a symbol or `client.unsubscribe_tick("0700.HK")` to remove one.
