## Get currency data

### Method name: get_currency

### Enter parameters

| Field      | Type                                  | Description              | Is it required |
| :--------- | :------------------------------------ | :----------------------- | :------------- |
| start_date | Optional\[str\]                       | Start date,eg:"20250702" | Optional       |
| end_date   | Optional\[str\]                       | End date,eg:"20250702"   | Optional       |
| fields     | Optional\[Union\[str, List\[str\]\]\] | Exchange rate list       | Optional       |

### Usage examples

#### Obtain some backtest factors of a single Hong Kong stock

```python
import tqx_data
result = tqx_data.get_currency(
    start_date="20260101",
    end_date="20260131",
    field=[],
)
print(result)
```
