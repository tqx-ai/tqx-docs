Use `get_factor` in the Qube sandbox to explore factor fields. Factor calculations use framework-provided fields instead of calling this method; see [Write factor code](/qube/research/factor/code).

## Get backtest factors for Hong Kong and US stocks

### Method name: get_factor

### Enter parameters

| Field      | Type                                  | Description                                                                                       | Is it required |
| :--------- | :------------------------------------ | :------------------------------------------------------------------------------------------------ | :------------- |
| start_date | str                                   | Start date,eg: "20250702"                                                                         | Required       |
| end_date   | str                                   | End date,eg: "20250702"                                                                           | Required       |
| symbol     | Optional\[Union\[str, List\[str\]\]\] | Stock code                                                                                        | Optional       |
| factors    | Union\[str, List\[str\]\]             | Factor list                                                                                       | Required       |
| type       | Optional\[str\]                       | Market: `hk` (default) or US `nb`; `us` is equivalent to `nb`. The old `ny` value is unsupported. | Optional       |

### Response parameters

Basic factor class:

| Field     | Type   | Description                  |
| :-------- | :----- | :--------------------------- |
| date      | str    | date                         |
| symbol    | str    | stock code                   |
| open      | double | opening price                |
| close     | double | closing price                |
| high      | double | highest price                |
| low       | double | lowest price                 |
| volume    | double | trading volume               |
| amount    | double | transaction amount           |
| pre_close | double | previous day's closing price |

HK base factor data also provides `turnover`; US provides `market_cap`. Check actual columns and coverage. A native field's existence does not establish factor-consumer support; validate and run saved factor source separately.

### Usage examples

#### Obtain some backtest factors of a single Hong Kong stock

```python
import tqx_data
result = tqx_data.get_factor(
    symbol="0700.HK",
    start_date="20260101",
    end_date="20260131",
    type="hk",
    factors=["symbol", "date", "close"],
)
print(result)
```
