### Method name: get_index_component

### Response parameters

| Field | Type | Description |
|:-------------|:-----|:---------------|
| index_symbol | str | index code |
| stock_symbol | str | stock symbol |
| added_date | str | date of inclusion into constituent stocks |
| deleted_date | str | date of deletion of constituent stocks |

### Usage examples

#### Obtain information on all Hong Kong stock index constituent stocks

```python
import tqx_data
result = tqx_data.get_index_component(
    market='hk',
    stock_symbol="",
    index_symbol="",
)
print(result)
```
