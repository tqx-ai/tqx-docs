## The Qube research loop

1. Start with a market question or hypothesis.
2. Query or prepare the data you need.
3. Create a factor or strategy.
4. Write and validate the source.
5. Run a factor analysis or strategy backtest.
6. Review metrics, trades, logs, and diagnostics.
7. Save a named version or tune a bounded parameter set.
8. Recheck the candidate on a different period.
9. Review and authorize any move toward trading separately.

<Warning>
  A saved factor or strategy is a research asset. Saving code does not run it, and a historical
  result does not guarantee future performance.
</Warning>

## Use Qube through three interfaces

<Tabs>
  <Tab title="Web workspace">
    Open the [Qube web workspace](https://www.tqx.ai/qube) to create and review research assets
    through conversation, the Factor Library, the Strategy Library, run history, and workspace
    files.
  </Tab>
  <Tab title="Qube CLI">
    Use `tqx research` for factor and strategy lifecycle commands, polling, results, versions, and
    tuning.
  </Tab>
  <Tab title="TypeScript SDK">
    Use `@tqx-ai/sdk` and `client.research` to write your own TypeScript program that creates
    research, runs backtests, and reads results.
  </Tab>
</Tabs>
