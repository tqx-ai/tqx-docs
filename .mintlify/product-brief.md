# Product brief

## Description

TQX documentation helps readers understand TQX as a product family, use Qube for AI-assisted quantitative research, query data through the correct runtime, and connect CLI workflows to trading.

## Primary audience

The primary audience is external readers, including people with no quantitative-research or coding background. Teach concrete workflows from simple concepts to deeper interpretation: explain each setting, why it matters, what to do, and how to read the result. Use a consistent worked example and annotated explanations around real product screenshots. Do not replace useful detail with broad claims. Keep exact schemas and integration contracts in API and code references, with clear links for advanced readers. Support both English and Traditional Chinese.

## Jobs to be done

- Understand what Qube is and choose the right entry point.
- Create, validate, analyze, backtest, version, and tune factors and strategies.
- Choose between Qube runtime data APIs and the local PyPI `tqx-data` package.
- Use the TQX CLI and TypeScript SDK with current Qube Next contracts.
- Move reviewed research toward trading without confusing research with execution.

## Motivation

Qube Next connects conversations, workspace context, data Skills, research assets, execution runs, results, and versions in one reproducible workflow. The docs must explain that workflow without exposing internal deployment details.
