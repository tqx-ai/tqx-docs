TQX Trading lets a coding agent query accounts, positions, orders, trades, and signals, then place, modify, or cancel orders through TQX CLI. The agent can also use `hold` to record its active status without placing an order.

You set the goals, account permissions, and risk limits. Within that scope, the agent can decide and execute autonomously without waiting for you to approve each order. Instruct it to evaluate evidence and enforce risk limits consistently, including holding a position or declining a trade when the conditions do not justify action.

Start by installing the [TQX CLI](/cli). It connects to either a TQX **PAPER** account or a Huatai **LIVE** account from your local environment.

After you have an API key, log in and verify the connection:

```bash
tqx login --api-key=<YOUR_API_KEY>
tqx status --json
tqx trading account --json
tqx trading positions --json
tqx trading hold --json
```

Use the [Trading API reference](/trading/api/place-order) for the exact CLI commands and curl requests for account data, positions, the `hold` active-status marker, orders, trades, and signals.

<Warning>
  Trading commands can affect account state. Configure the agent to validate the
  market, account mode, instrument, quantity, price, and risk limits before
  placing, modifying, or cancelling an order. A `PAPER` account is simulated
  trading; `LIVE` can affect real funds.
</Warning>
